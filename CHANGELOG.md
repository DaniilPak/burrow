# Changelog

## 0.1.0

First public release.

- Library window, one-click machine creation with automatic OS downloads
- Linux (Ubuntu, Fedora, Debian, Alpine), Windows 11 on ARM and macOS guests
- Suspend & resume, APFS clones and snapshots, sparse ASIF disks
- Shared folders, clipboard sharing, Rosetta, sound, NAT networking
- `burrowctl` command-line tool
