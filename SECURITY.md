# Security policy

Burrow runs virtual machines, writes setup files that can contain guest account
passwords, and downloads installers from the internet, so security reports matter.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/DaniilPak/burrow/security/advisories/new).

Include what an attacker could do, the affected version or commit, and steps to
reproduce. You'll get a reply within a week. Once a fix is released, you'll be
credited in the release notes unless you'd rather not be.

## Supported versions

Only the latest commit on `main` receives security fixes.
